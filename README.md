# Machine Learning Study

회귀·분류 모델의 계산 과정부터 신경망과 이미지 분류까지 정리한 개인 학습 기록.
수식으로 계산한 결과를 코드와 그래프로 확인하고, 모델 구성에 따른 오차와 학습 시간 비교.

## 목적

- 손실함수와 기울기를 구현하며 가중치가 갱신되는 과정 이해
- 학습 오차와 검증 오차를 나눠 보고, 모델이 복잡해질 때 생기는 과적합 확인
- 수치 미분·오차역전파·Keras 구현의 계산 방식과 학습 결과 비교
- 이미지 분류 모델의 구조와 학습 조건을 바꿔 가며 결과 확인

## 실험 방법

### 회귀와 분류

수식으로 만든 합성 데이터로 학습 과정 확인.
회귀에서는 예측값과 정답의 차이를 제곱해 평균낸 평균제곱오차(MSE)를 사용하고,
분류에서는 정답 클래스에 부여한 확률을 평가하는 교차 엔트로피 사용.

- 회귀: 기울기에 따라 가중치를 갱신하는 경사하강법과 수식으로 구한 해 비교
- 모델 복잡도: 가우스 기저 함수 개수를 바꾸며 오차 변화 확인
- 검증: 데이터를 나눠 평가하는 홀드아웃, K겹 교차 검증, 하나씩 제외하는 LOOCV 적용
- 분류: 손실함수와 기울기를 구현하고 `scipy.optimize.minimize`의 CG 방법으로 최적화

회귀 데이터는 실제 신체 측정값이 아닌 합성 데이터.
03에서는 생성한 키 값을 변환해 몸무게 입력을 만들기 때문에 실제 신체 예측 성능으로 해석하지 않음.
02에 표시한 오차는 학습 데이터의 오차이며, 독립적인 테스트 성능과 구분.

### 신경망 학습 방식

입력 2개 → 은닉 뉴런 2개 → 출력 클래스 3개의 신경망 사용.

- 수치 미분: 가중치를 조금씩 바꿨을 때 생기는 오차 차이로 기울기 근사
- 오차역전파: 출력 오차를 이전 층으로 전달하며 기울기 계산
- Keras: 같은 층 구성을 라이브러리로 구현해 학습

수치 미분과 오차역전파의 기울기를 대조하고 학습 곡선·분류 경계·소요 시간 비교.
수동 구현은 학습률 0.5, 1,000회 갱신. Keras는 SGD 학습률 1.0, 1,000 epochs, 배치 크기 100 사용.
초기화와 학습 설정 차이가 있으므로 구현 방식만의 효과로 단정하지 않음.

### 이미지 분류

MNIST는 손글씨 숫자, Fashion-MNIST는 의류 이미지 데이터.
모두 28×28 흑백 이미지와 10개 클래스로 구성.

MNIST는 Sigmoid·ReLU 완전연결 모델, 기본 CNN, 확장 CNN을 비교.
학습용 60,000장 중 5,000장을 검증에 사용하고, 테스트 10,000장은 분리.
기본 모델은 10 epochs, 확장 CNN은 30 epochs이므로 구조만의 차이를 분리한 비교는 아님.

## Fashion-MNIST 비교

합성곱 층을 늘리거나 학습 중 일부 뉴런을 제외하는 Dropout을 적용했을 때의 변화 확인.

| 항목 | 설정 |
|---|---|
| 데이터 분리 | 학습 55,000장 / 검증 5,000장 / 테스트 10,000장 |
| 전처리 | 픽셀값 0~1 변환, 정답 원-핫 인코딩 |
| 학습 횟수 / 배치 크기 | 30 epochs / 128 |
| 가중치 갱신 / 손실함수 | Adam / Categorical Cross-Entropy |
| 모델 선택 | 마지막 epoch의 검증 정확도가 가장 높은 모델 |
| 최종 평가 | 선택이 끝난 모델만 테스트 데이터로 평가 |

| 모델 | 구성 |
|---|---|
| A | 합성곱 1층 + Dense 64 |
| B | 합성곱 2층 + Dense 64 |
| C | 합성곱 2층 + Dense 128 + Dropout 0.3 |

C는 Dense 크기도 함께 바꿨으므로 Dropout만의 효과로 해석하기 어려움.
구조별 비교 결과와 오분류 예시는 노트북에 기록.

### 실행 결과

Python 3.10.20 / TensorFlow 2.10.0 / macOS CPU에서 전체 셀 재실행한 결과.

| 모델 | 검증 정확도 | 검증 손실 |
|---|---:|---:|
| A | 91.76% | 0.3609 |
| B | 92.04% | 0.2975 |
| C | 92.52% | 0.2730 |

검증 정확도로 선택한 모델: **C**.
선택 완료 후 테스트 정확도 **91.98%**, 테스트 손실 **0.3118**.

한 번의 실행 결과이며 초기 가중치와 실행 환경에 따라 수치는 달라질 수 있음.
개별 학습 시간의 합계와 전체 실행 시간이 일치하지 않아 이번 결과표에서는 시간 비교 제외.
노트북에 남긴 시간 출력은 성능 비교 근거로 사용하지 않음.
6개 노트북 모두 새 커널에서 첫 셀부터 끝까지 실행 확인.
패키지 의존성 검사 통과. 새 가상환경에서의 재설치와 다른 OS 실행은 별도 확인 대상.

## 실행

Python 3.10 환경에서 실행.

```bash
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m notebook
```

각 노트북은 커널 초기화 후 첫 셀부터 순서대로 실행.
앞에서 선언한 함수와 변수를 뒤쪽에서 사용하므로 중간 셀만 실행하면 오류가 날 수 있음.
MNIST·Fashion-MNIST는 최초 실행 시 Keras를 통해 다운로드.
데이터 파일, 가상환경, 학습 모델, 체크포인트는 저장소에서 제외.
